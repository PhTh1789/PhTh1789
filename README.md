## Featured Project

### [xepthung.tech](https://xepthung.tech) — 3D Cargo Loading Optimization Platform

An individual graduation project that helps drivers and logistics businesses plan cargo placement for trucks and containers through **interactive 3D visualization and heuristic-based cargo optimization**.

Designed and developed end-to-end, covering **UI/UX, frontend, backend, database, authentication, optimization logic, and deployment**.

**Tech:** React · TypeScript · Tailwind CSS · shadcn/ui · Three.js · React Three Fiber · WebGL · FastAPI · PostgreSQL · Supabase

[Live Demo](https://xepthung.tech) · [GitHub Repository](https://github.com/PhTh1789/XepThung)
